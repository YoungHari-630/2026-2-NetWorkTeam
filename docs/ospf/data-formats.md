# OSPF Engine Data Formats

All structures are plain JSON-compatible dicts and lists. Complete, real
examples (generated by `python -m backend.ospf.demo --write-examples
docs/ospf/examples`) are in [`examples/`](examples/):

| File | Content |
| --- | --- |
| `01_initial_snapshot.json` | Basic topology at t=0, converged |
| `02_step_link_failure.json` | `step()` result for the `BD` failure |
| `03_step_lsa_reception.json` | `step()` result: A receives B's new LSA at t=1 |
| `04_snapshot_t1_converging.json` | Snapshot at t=1: LSDBs differ, `converging` |
| `05_final_snapshot.json` | Snapshot after `run_until_idle()`, with full history |

A test (`test_documented_examples_match_a_real_run`) fails if these files no
longer match the engine's output.

## Snapshot

```text
{
  "time":            number,                      virtual simulation time
  "config":          SimulationConfig.to_dict(),
  "topology":        {"routers": [...], "links": [...]},   physical ground truth, shared format
  "lsdbs":           {router_id: LSDB},
  "routing_tables":  {router_id: {destination: RouteEntry}},
  "pending_events":  [PendingEvent],              in processing order
  "event_history":   [HistoryRecord],             [] when include_history=False
  "convergence":     Convergence,
  "partition":       Partition
}
```

### LSDB

```json
{
  "router_id": "A",
  "version": 5,
  "lsas": [LSA, ...]
}
```

`lsas` are sorted by origin ID. `version` increases with every installed LSA.

### LSA

```json
{
  "origin_router_id": "B",
  "sequence_number": 2,
  "timestamp": 0,
  "links": [
    {"link_id": "AB", "neighbor_id": "A", "cost": 1, "active": true},
    {"link_id": "BD", "neighbor_id": "D", "cost": 1, "active": false}
  ]
}
```

`timestamp` is the virtual time when the LSA was originated.

### RouteEntry

```json
{"destination": "D", "next_hop": "C", "path": ["A", "C", "D"], "cost": 5, "reachable": true}
```

The router's own entry has `next_hop: null`, `cost: 0`, `path: [self]`. An
unreachable destination has `next_hop: null`, `cost: null`, `path: []`,
`reachable: false`, the same convention as `build_routing_table`. Routing
tables list every router that appears in the local LSDB.

### PendingEvent (also the `event` of a `step()` result)

```json
{
  "event_id": "E00005",
  "time": 1,
  "event_type": "lsa_reception",
  "router_id": "A",
  "payload": {"lsa": LSA, "from_router": "B", "link_id": "AB", "reason": "flood"}
}
```

| `event_type` | `router_id` | `payload` |
| --- | --- | --- |
| `link_failure`, `link_recovery` | `null` | `{"link_id"}` |
| `link_cost_change` | `null` | `{"link_id", "cost"}` |
| `lsa_generation` | originating router | `{"trigger", "link_id"}` |
| `lsa_reception` | receiving router | `{"lsa", "from_router", "link_id", "reason": "flood" \| "database_exchange"}` |
| `spf_calculation` | router | `{}` |

### HistoryRecord

```json
{
  "record_id": 14,
  "time": 1,
  "event_type": "lsa_reception",
  "router_id": "A",
  "caused_by": "E00005",
  "description": "A received LSA B#2 from B via AB.",
  "details": {"origin_router_id": "B", "sequence_number": 2, "from_router": "B", "link_id": "AB"}
}
```

`caused_by` is the ID of the queued event whose processing produced the
record. Every record comes from real engine processing; none are added for
display purposes.

| `event_type` | Main `details` keys |
| --- | --- |
| `simulation_initialized` | `router_count`, `link_count`, `converged` |
| `link_failure` / `link_recovery` | `link_id`, `source`, `target`, `previous_state`, `new_state` |
| `link_cost_change` | `link_id`, `source`, `target`, `previous_cost`, `new_cost` |
| `link_change_ignored` | `requested`, `link_id`, `reason` |
| `lsa_generation` | `lsa`, `trigger`, `link_id` |
| `lsa_transmission` | `origin_router_id`, `sequence_number`, `to_router`, `link_id`, `reason`, `arrival_time`, `reception_event_id` |
| `lsa_reception` | `origin_router_id`, `sequence_number`, `from_router`, `link_id` |
| `lsa_rejected` | `reason` (`duplicate` \| `outdated`), `origin_router_id`, `sequence_number`, `stored_sequence_number`, `from_router`, `link_id` |
| `lsa_dropped` | `origin_router_id`, `sequence_number`, `link_id`, and `from_router` or `to_router` |
| `lsdb_update` | `origin_router_id`, `sequence_number`, `previous_sequence_number`, `lsdb_version` |
| `spf_calculation` | `lsdb_version` |
| `routing_table_update` | `changes: [{"destination", "previous": RouteEntry, "current": RouteEntry}]` |
| `convergence_status_change` | `converged`; when `true` also `started_at`, `converged_at`, `duration`, `trigger_event_ids`, `partitioned` |

### Convergence

```json
{
  "converged": false,
  "status": "converging",
  "pending_protocol_events": 2,
  "relevant_pending_events": 2,
  "reasons": ["2 relevant protocol event(s) pending.", "A does not hold the latest LSA of D."],
  "current_episode_started_at": 0,
  "last_change_time": 0,
  "last_converged_time": 0,
  "reconvergence_episodes": [
    {"started_at": 0, "converged_at": 3, "duration": 3, "trigger_event_ids": ["E00001"], "partitioned": false}
  ]
}
```

`status` is `"converged"` or `"converging"`. `pending_protocol_events` counts
all queued generation, reception and SPF events. `relevant_pending_events`
counts only those that can still change state (see the convergence policy in
`README.md`).

### Partition

```json
{
  "partitioned": true,
  "component_count": 2,
  "components": [["A", "C"], ["B", "D"]],
  "isolated_routers": []
}
```

Components are computed from physical active links and listed in topology
order.

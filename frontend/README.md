# Frontend workspace

Role 3 will build the browser UI here with HTML, CSS, JavaScript, and Cytoscape.js.

The API base URL during local development is `http://127.0.0.1:8000`. See
[`../docs/api-contract.md`](../docs/api-contract.md) for the topology schema,
API examples, and error responses. The UI and graph visualization are planned;
no frontend functionality is implemented yet.
